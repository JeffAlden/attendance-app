Attendance operation

IN only records every accepted scan as an entry, even if a reader requests OUT. It disables automatic OUT toggling and anti-passback. The dashboard shows today's entrants; physical occupancy and hours worked cannot be determined without exit scans. Earlier scan history is preserved.

Attendance endpoint:

For online deployment configure TLS at your proxy and restrict device traffic using a firewall or VPN. Serial matching is not authentication. Attendance and contact/status requests are supported; user/template synchronization is not implemented.

  1. Give the reader a fixed LAN IP and enable TCP communication, usually port 4370.
  2. Run this app on the same LAN, or provide a private VPN route from the online server to the reader.
  3. Save the reader IP, port and interval. Automatic polling starts within 5 seconds; use Sync now for a manual download.
  4. Enroll users on the terminal using their employee Device User ID. Downloaded logs stay on the terminal; repeated downloads skip stored punches.

Supports ZK TCP 40-byte attendance records with communication key 0. Unsupported firmware or protected readers report an error. Validate compatibility on your physical reader before production use.
