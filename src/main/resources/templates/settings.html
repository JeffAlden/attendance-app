Attendance operation

IN only records every accepted scan as an entry, even if a reader requests OUT. It disables automatic OUT toggling and anti-passback. The dashboard shows today's entrants; physical occupancy and hours worked cannot be determined without exit scans. Earlier scan history is preserved.

Fingerprint reader connection

ZKTeco ADMS / Push: the reader sends attendance to this app. Reader IP and port are saved as connection reference details; this app does not initiate an SDK connection or change the reader's network configuration.

Enter the serial reported by the reader to apply its direction below.
Connect the physical reader
  1. Give this PC a fixed LAN IP address.
  2. On the reader, open its ADMS / Cloud Server settings and set Server Address to this PC's LAN IP (not localhost).
  3. Set Server Port to , and allow that TCP port through the PC's firewall. Saving reader details above does not change this app's listening port.
  4. Enroll employees on the physical reader using the Device User ID from Employees. Scans are received at /iclock/cdata.
